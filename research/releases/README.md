# Released models

Three models trained for Language Engine, published with weights on
[Hugging Face](https://huggingface.co/conradcompagna). Each folder holds the model
card, a loader script, the evaluation record and licence files.

| Folder | Model |
|---|---|
| [arabic-clitic-tokenizer/](arabic-clitic-tokenizer/) | Arabic tokenizer and clitic (MWT) expander |
| [sanskrit-sandhi-tokenizer/](sanskrit-sandhi-tokenizer/) | Sanskrit tokenizer and sandhi (MWT) expander |
| [sanskrit-interpretive-ner/](sanskrit-interpretive-ner/) | Sanskrit named-entity recognizer with 18 semantic categories |

Scores for all custom components are in [`../models/README.md`](../models/README.md).
