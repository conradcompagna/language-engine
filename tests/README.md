# Regression checks

Run `python -m tests.test_mwt_realign_dp` from the repository root with Python 3.12.

The existing Sanskrit and surface-alignment fixtures verify that expanded multi-word tokens retain contiguous coverage and valid character maps. They need neither model weights nor dictionary databases. A failed assertion produces a nonzero exit status.

CI runs this check, Ruff formatting and undefined-name checks, and syntax checks for authored browser JavaScript. Live NLP, account, payment, and document integrations require separately configured resources and services.
